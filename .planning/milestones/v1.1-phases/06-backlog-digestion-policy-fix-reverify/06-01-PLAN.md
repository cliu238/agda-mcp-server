<objective>
Fix the v1.0 audit's headline W2 defect: ORCL-02's cheat-detection policy is currently derived ONLY from the corpus root's `.agda-lib` `name:` field, so a case-mismatched corpus (the real CHG shape: `.agda-lib` name `Codex-Homotopy-Group` vs on-disk policy file `codex-homotopy-group.json`) silently degrades to `no-policy` abstention on a case-sensitive filesystem and silently RESOLVES (masking the bug) on macOS APFS. Add runtime policy-key passthrough (`--policy` flag on both `run-oracle.mjs` and `dogfood-wrapup.mjs`, plus corpus-derived resolution from `fuel-corpora.json`), make resolution case-exact on every platform via a directory-listing check, and make every expected-but-unresolvable key fail loudly.

Purpose: POLICY-01 — correctness prerequisite for all Phase-7 team-channel judging (a bundle from another machine must never silently abstain from cheat-filing).
Output: patched scripts + a regression test suite proving the loud-fail behavior, ungated so it runs on ubuntu-latest CI (case-sensitive ext4) — the phase's hard acceptance gate.
</objective>
