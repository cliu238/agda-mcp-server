## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Staged CaptureArtifact JSON (crosses machines by design) -> scripts/verify-cold-replay.mjs -> local filesystem | `manifest.inlinedFirstPartySources[].path` is untrusted, cross-machine input — this script's own header states it is meant to run against artifacts staged elsewhere, so a shared or tampered capture must be treated as untrusted |
