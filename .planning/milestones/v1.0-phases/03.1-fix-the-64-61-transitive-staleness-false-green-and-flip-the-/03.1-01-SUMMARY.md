# Phase 03.1 Plan 01: Fix runLoadNoMetas Terminus Gap Summary

**Generalizes AgdaTransport's `awaitGoalTerminus` boolean into a `loadTerminusMode: "metas" | "strict" | null` enum and flips `runLoadNoMetas` to request the strict guard, closing the `e38f90a` metas-vs-no_metas completion-detection asymmetry behind the #64/#61 transitive-staleness false-green.**
