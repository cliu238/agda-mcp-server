## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-07-06 | Tampering | AppleDouble/.DS_Store junk leaking local filesystem metadata into the uploaded archive | mitigate | `COPYFILE_DISABLE=1` on the tar child + explicit `--exclude=.DS_Store --exclude=._*`, verified by a pack-then-extract round-trip test |

| T-07-SC | Tampering (supply chain) | npm/pip/cargo installs | n/a | Zero new npm dependencies added by this plan (`node:child_process`, `node:zlib`, `node:stream`, `node:fs`, global `fetch` only) — Package Legitimacy Gate not triggered |
