<objective>
## Phase Goal

**As a** maintainer dogfooding this server (or an AI coding agent such as Codex or Claude Code, driven interactively by the maintainer), **I want to** point my MCP session at pinned real Agda corpora through a recording proxy that captures defects and auto-persists them, then wrap up a finished run through the oracle triad and an anti-phantom N-times gate, **so that** harvesting real defects becomes a repeatable, on-demand loop instead of a one-off manual campaign that silently produces zero structured reports (the exact gap Codex-Homotopy-Group's multi-week campaign exposed).

*(Same phase-level user story as 05-01/05-02 — see 05-01's objective for the full MVP_MODE adaptation note. This plan is a THIRD slice, running in parallel with 05-04: after it lands, a finished dogfood run can be judged end to end with one command — `npx tsx scripts/dogfood/dogfood-wrapup.mjs <run-id>` — that composes the ALREADY-COMPLETE Phase-2 oracle triad with a NEW anti-phantom N-times gate and either files a real defect into the ALREADY-COMPLETE Phase-4 queue or tags it flaky, closing success criterion 4. This plan depends only on 05-02 (it reads the run-report.json shape 05-02's transcript-writer.mjs defines); it does not depend on 05-04, whose Skill documents this plan's CLI shape as fixed by this plan's own text, not by waiting for its execution.)*

Deliver the post-run wrap-up pipeline: `flake-classify.mjs`'s `classifyFlakiness` (N fresh warm-session replays of the SAME recorded action, comparing only against each other — never a repeated cold ORCL-01 spawn, and never re-running ORCL-02's static scan) and `dogfood-wrapup.mjs`'s `wrapUpCapture` (composes the unchanged Phase-2 `runOracle` with the new flake gate, filing only genuine candidate defects into the unchanged Phase-4 queue as `new`, and routing flaky results to a gitignored side-channel file the frozen queue schema has no slot for).

Purpose: this is success criterion 4 — the anti-phantom gate that keeps timing/idle phantoms (#65/#66's own family) out of the queue as false "deterministic" defects, while still surfacing them as visible, non-discarded signal.
Output: `scripts/dogfood/flake-classify.mjs`, `scripts/dogfood/dogfood-wrapup.mjs`, and passing unit tests (DI-driven, no real Agda) plus one real-Agda integration test proving the mechanism against the actual, already-fixed flagship fixture.
</objective>
