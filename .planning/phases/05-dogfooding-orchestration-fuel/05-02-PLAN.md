<objective>
## Phase Goal

**As a** maintainer dogfooding this server (or an AI coding agent such as Codex or Claude Code, driven interactively by the maintainer), **I want to** point my MCP session at pinned real Agda corpora through a recording proxy that captures defects and auto-persists them, then wrap up a finished run through the oracle triad and an anti-phantom N-times gate, **so that** harvesting real defects becomes a repeatable, on-demand loop instead of a one-off manual campaign that silently produces zero structured reports (the exact gap Codex-Homotopy-Group's multi-week campaign exposed).

*(Same phase-level user story as 05-01 — see that plan's objective for the full MVP_MODE adaptation note. This plan is the SECOND slice: after it lands, a maintainer can genuinely point an MCP client at `scripts/dogfood/dogfood-run.mjs` instead of the bare server and get real, working transparent proxying + transcript recording + auto-persisted captures — the D-01 recording-proxy mode itself, the centerpiece success criterion 3 delivers. Task ordering below deliberately puts the end-to-end integration test FIRST (it fails until Task 3 lands), matching MVP_MODE's "failing end-to-end test for the happy path" pattern, then builds the interface (`transcript-writer.mjs`) before its consumer (`dogfood-run.mjs`) per this project's Interface-First convention.)*

Deliver the transparent recording proxy: a line-buffered stdio tee between an agent and the real spawned `dist/index.js`, gated by PROC-01's mechanical hard gate (Plan 05-01's `loadTaskManifest`), that unconditionally sets `AGDA_MCP_CAPTURE=1` on the child, records an unbounded transcript, detects and auto-persists every `agda_capture_session` result, and writes a per-tool-call-count/duration run report on exit — all without ever constructing a second `AgdaSession` (#39).

Purpose: this is the mechanical heart of PROC-01 — the piece that turns "an agent might remember to file a bug" into "every dogfood session leaves a durable, auto-persisted record regardless of what the agent does."
Output: `scripts/dogfood/transcript-writer.mjs`, `scripts/dogfood/dogfood-run.mjs`, and passing unit + integration tests proving transparent passthrough, the hard gate, the unconditional capture env var, and auto-persist.
</objective>
