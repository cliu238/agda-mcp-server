a captured session judged "true green" only when all three oracle predicates — the server-faithfulness
differential, the soundness-hygiene scan, and the conformance proxy — agree, **so that** a fresh

the fix was sound, and the right theorem was actually proved.

## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Captured artifact JSON (may have crossed machines) -> filesystem writes + subprocess argv | `inlinedFirstPartySources[].path`, `agdaBinaryPath`, `mergedArgv` are all untrusted data driving file writes and a child-process invocation |
| Cold Agda subprocess stdout -> pass/server-false-green-candidate verdict | An idle-timeout-based response collector infers "the load finished"; incomplete evidence must never read as a positive (or negative) result |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-02-03-01 | Tampering | `materializeCaptureEnvironment` source materialization | mitigate | Every `inlinedFirstPartySources[].path` is resolved through `resolveFileWithinRoot` before any `writeFileSync`; a `..`-traversal entry is skipped, never written outside the temp replay directory — this is the CR-01 shape, designed out via SSOT reuse rather than a second hand-rolled containment check (Task 1) |
| T-02-03-02 | Repudiation | `runColdLoadAndDiff`'s terminus/timeout handling | mitigate | An evidence-free or truncated cold response stream (no `InteractionPoints`/`AllGoalsWarnings`/`Error`) is gated to `INCONCLUSIVE(terminus)`, never a false `pass` — this is the CR-02 shape, generalized into the 7-probe framework (Task 2) |
| T-02-03-03 | Tampering | version-match probe `execFileSync` invocation | mitigate | `execFileSync(agdaBinaryPath, ["--version"])` always uses the argv-array form, never shell-interpolated, even though `agdaBinaryPath` originates from untrusted artifact data (Task 1) |
| T-02-03-04 | Tampering | library-registration replay | mitigate | `manifest.agdaDirContents` is written verbatim into a fresh temp `AGDA_DIR`; `createLibraryRegistration()` (non-deterministic, reads the LIVE machine's `~/.agda`) is never called from this module (Task 1) |
