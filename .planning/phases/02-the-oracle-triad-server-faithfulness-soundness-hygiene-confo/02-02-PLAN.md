## Phase Goal

**As a** maintainer or AI agent (Codex/Claude Code) dogfooding the Agda MCP server, **I want to** get
a captured session judged "true green" only when all three oracle predicates — the server-faithfulness
differential, the soundness-hygiene scan, and the conformance proxy — agree, **so that** a fresh
`agda` re-run's necessarily-insufficient pass is never mistaken for proof the server told the truth,
the fix was sound, and the right theorem was actually proved.

<objective>
Build ORCL-02: a static token/pragma scan over a captured artifact's source diff and the target's
fully-transitive dependency closure, diffed against a per-project sanctioned-axiom whitelist, that
catches soundness cheats a fresh `agda` re-run (ORCL-01) structurally cannot see — introduced

this predicate.

staged capture and get `clean` / `cheat-flagged` / `no-policy`, backed by a real interim policy file
and new pragma-vocabulary test fixtures.
