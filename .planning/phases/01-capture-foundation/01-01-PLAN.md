<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Agent -> agda_capture_session tool input | note is untrusted free text from an MCP client |
| Tool -> filesystem (.agda-mcp/captures/) | Staging path built from repoRoot + fixed relative segments, never from caller input |
| Tool -> dedup index file | Read-only in this plan; malformed/oversized index.json must not crash the tool |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-01-01 | Tampering | register-capture-session.ts staging write | mitigate | Staging path is `join(repoRoot, ".agda-mcp", "captures", fileName)` built entirely from server-derived segments (repoRoot + fingerprint, which is a hex hash) - never from raw caller-supplied path text; use writeFileAtomic (temp-file + rename, O_CREAT|O_EXCL) from safe-source-io.ts rather than a fresh fs.writeFileSync path |
| T-01-02 | Information Disclosure | dedup-index.ts read | mitigate | readDedupIndex guards with existsSync + try/catch around JSON.parse; malformed index.json downgrades to an empty Map with a console warning, never throws or leaks a stack trace to the tool caller |
| T-01-03 | Denial of Service | dedup-index.ts / index.json growth | accept | Phase 1's index is a minimal read-only lookup (write-side lives in the out-of-band scripts/promote-capture.mjs script, Phase-1-out-of-scope for this plan); unbounded index growth is a Phase-4 QUEUE-01 concern, not this plan's |
| T-01-SC | Tampering | npm/pip/cargo installs | mitigate | No new package installs in this plan - N/A |

</threat_model>
