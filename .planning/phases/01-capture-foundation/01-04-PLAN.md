<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Agent-supplied beforeSource/expectedSignature -> oracle-substrate.ts | Untrusted free text from the MCP tool caller, stored as opaque strings only (never parsed/executed/shell-interpolated) |
| oracle-substrate.ts -> git CLI | git show is invoked with execFileSync (argv array, no shell), the path argument is repo-root-relative and derived from session.currentFile, not raw caller input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-04-01 | Tampering | resolveBeforeSource's git show invocation | mitigate | execFileSync with an argv array (["show", "HEAD:<path>"]) - never execSync/string-shell interpolation - so a crafted file path cannot break out into shell metacharacters |
| T-04-02 | Denial of Design safety | buildOracleSubstrate live Cmd_goal_type call hanging or crashing the capture | mitigate | Every session.sendCommand call is wrapped in try/catch with a null fallback; a stuck/failed Agda process (the exact scenario capture exists to snapshot) must never prevent the capture tool itself from returning a result |
| T-04-03 | Information Disclosure | afterSource reading arbitrary on-disk content | accept | Reuses readAgdaSourceFile's existing O_NOFOLLOW + 512 KiB cap (safe-source-io.ts) - same trust level as every other tool that reads the loaded source file |

</threat_model>
