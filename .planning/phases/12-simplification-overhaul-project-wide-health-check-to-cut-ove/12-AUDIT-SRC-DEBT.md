## Dead-Code and Unused-Export Scan — Methodology

**Method used:** manual, script-assisted export/import cross-reference (no `npx knip`). Concretely, for every top-level `export function|const|class|interface|type|enum` declared in an in-scope `src/` file (102 files after excluding `src/tools/**` and the three Plan-12-03-owned `src/session/*.ts` files), a Python pass loaded the full text of every `.ts`/`.mjs` file under `src/`, `scripts/`, and `test/` (439 files, ~74k lines) once, then ran a `\bSYMBOL\b` word-boundary regex against every other file to count external (non-declaring-file) references. This catches usage regardless of import-path style (direct, barrel re-export, or renamed-on-import — the original name always appears at least once at the import site).

**478 exported symbols were checked.** A companion whole-file reachability pass (do any `src/scripts/test` files import a given in-scope file's basename at all?) found **zero** whole-file dead candidates — every one of the 102 in-scope files has at least one production (`src/` or `scripts/`) importer. The finding at the symbol level is narrower and more interesting: **20 exported value symbols** (function/const/class/enum — the strong dead-code signal category) have zero external references; **46 exported type/interface symbols** have zero *lexical* external references, but this is a weak signal on its own (TypeScript's structural typing lets a type be "used" purely via inference without ever being named at the call site), so type-only zero-usage findings were **not** treated as dead-code candidates without independent confirmation — none were promoted to the cut list below.

**Why `npx knip` was not run for this category:** 12-RESEARCH.md's own Environment Availability section already concludes the manual/grep methodology is sufficient at this repo's size (150 `src/` files) and that `knip` requires an explicit `entry` config to avoid flooding the report with `scripts/` CLI false positives (Pitfall 4) — a config-authoring cost this plan's scope (a single audit pass over ~100 non-tool files) doesn't recoup.
